# 老菊の音箱 Mod v1.3.0

适配再再启程 / One Way Tickets 0.8.0.3，以及我另一个仓库的自制 DPS Mod  (https://github.com/waltermeron/OneWayTickets-DPS-Mod)

解压zip文件 覆盖到根目录，可直接启动。

将SpeakerMod\assets 中的365里路.mp3，更换为其他歌曲，并也改名为365里路.mp3，即可替换为其他歌曲

## v1.3.0 音乐渐变

- 按界面显示的剩余米数，在最后约 20m 平滑降低《365里路》的音量；到达 0m 时为零。
- 进入休整界面后，原版背景音乐用约 1.5 秒从静音渐渐恢复。
- 恢复以游戏当时计算的背景音乐音量为基准，保留游戏自身的休整音量变化、音量设置和静音状态。
- 重复攻击、回退或重复休整事件不会重启当前渐变；下一次出发首次攻击重新正常播放。

## 具体内容

装备替换摄魂铃的“老菊の音箱  ”后首次攻击播放《365里路》，重复攻击不重播；音乐音量跟随游戏 BGM 设置，暂停时音乐和动画暂停。

## 安装与更新

当前目录已安装 v1.3.0，可直接启动游戏。

分发包请解压至游戏根目录。已有旧版音箱 Mod 时，先关闭游戏，再双击 `SpeakerMod/更新.cmd`。首次安装则双击 `SpeakerMod/安装.cmd`。更新保留原始卸载备份，并额外保存更新前 DLL 快照。

卸载时关闭游戏，双击 `SpeakerMod/卸载.cmd`，恢复音箱 Mod 安装前的游戏和 DPS DLL。卸载或更新 DPS Mod 前请先卸载音箱 Mod。游戏或其他 Mod 的 DLL 不匹配时，脚本会停止以避免覆盖不同版本。

本包适配上述当前游戏/DPS 版本。安装、更新、卸载均不修改游戏存档、DPS 历史或设置。

## 资源与源码

- `assets/speaker.png`：车上音箱原图，31×64 像素。
- 物品图标在运行时将原图居中放入 96×96 透明画布，不拉伸音箱图案。
- `assets/speaker-control.png`：战斗面板音箱，21×48 像素，3 色金橙色和透明背景；暗状态由运行时生成。
- `assets/speaker-control-preview.png`：深棕底、4 倍点采样预览。
- `src/Speaker.cs`：外观、图标、面板、音乐与隔离自检。
- `src/Patch.cs`：保留 DPS 插桩的游戏补丁工具。
- `backup/` 和 `installed.json`：本机卸载/校验资料，不包含在分发包。
